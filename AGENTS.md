# Eclipse Sentinel / ULTRON — Codex context

Этот файл — короткий маршрутизатор проекта. Общие правила Codex, Git, UX и security находятся в глобальном `AGENTS.md` и `E:/projects/AGENTS.md`; не дублировать их здесь.

## Перед работой

1. Подтвердить точный Git root, текущую ветку и dirty state.
2. Прочитать `E:/projects/AGENTS.md`, этот файл и `docs/PROJECT-CONTEXT.md`.
3. Найти существующий статус, audit или handoff текущей задачи; старые отчёты перепроверять.
4. Читать только код и документы, которые нужны для запроса. Не читать `.env`, ключи и секретные хранилища.

## Цель продукта

Sentinel должен стабильно принимать текстовые и голосовые команды, выполнять разрешённые действия и сообщать настоящий результат. Временная нестабильность голоса не должна лишать пользователя рабочего текстового пути.

## Критерий готовности

Команда считается выполненной только после реального побочного эффекта или честной ошибки: ввод → распознавание → разбор намерения → проверка полномочий → выполнение инструмента или OS-действия → результат → подтверждение или восстановление.

## Проверка изменений

Для voice, realtime, OS-инструментов и авторизации проверять успешные, запрещённые, просроченные, отменённые и повторные команды в фактическом runtime. Не записывать секреты и лишнее приватное аудио. После работы указать точные проверки и незакрытые риски.
